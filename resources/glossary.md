# Small glossary

| Term | Meaning in this project |
| --- | --- |
| Model | The AI component that interprets information and produces an output or proposes a next action. |
| Context | The information available to the model for a particular step. |
| Tool | A capability that software exposes for the AI to request, with defined inputs and results. |
| Runtime | The software that prepares model calls, executes permitted actions and returns their results. |
| State | What is actually true in the product at a particular moment. |
| Feedback loop | An action produces a result that becomes information for a subsequent decision. |
| Human edition | The readable book with its own language, edition and page numbering. |
| AI edition | Reference knowledge and guidance matched to a specific human edition. |

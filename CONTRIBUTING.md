# Feedback and corrections

Use a GitHub issue to report a correction or suggest an improvement. Please include the language, edition, page or section, the relevant text, and your proposed correction or question. For code, include the example version and a minimal reproduction when possible.

Do not include API keys, private customer records or confidential information. Discussion and pull requests do not change the publication status of an edition; accepted updates will appear with the relevant edition and correction record.

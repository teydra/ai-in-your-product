## Wann der Agent weiterarbeitet und wann er aufhört

Der wiederholte Ablauf heißt Agenten-Loop: Das Modell fordert eine Aktion an, die Runtime verarbeitet sie und liefert das Ergebnis zurück. Mit diesem erweiterten Kontext entscheidet das Modell über den nächsten Schritt.

Wir müssen dafür nicht jeden denkbaren Fehler als festen Gesprächspfad vorprogrammieren. Liefert eine Dateisuche keinen Treffer, kann das Modell anders suchen. Zeigt ein Test die falsche Rundung, kann es die Implementierung korrigieren. Die Runtime stellt die Werkzeuge und ihre Grenzen bereit; die Wahl des nächsten sinnvollen Schritts kann beim Modell bleiben. Hier wird die Stani-KI-Methode aus der Einleitung im System sichtbar: Die KI interpretiert Ziel und Ergebnisse. Die Software stellt erreichbare Fähigkeiten, echten Zustand und kontrollierte Ausführung bereit.

TypeSafe AI · Jev: POST /v1/systemone.

~~~text
{
  "model": "jev-latest",
  "state":
    "Wo bleibt mein Paket? Es sollte gestern da sein.",
  "questions": {
    "route": {
      "type": "choice",
      "instructions":
        "Welches Supportteam ist zuständig?",
      "criteria": {
        "shipping":
          "Lieferung oder Lieferstatus",
        "billing": "Rechnung oder Zahlung",
        "other": "Keines dieser Themen"
      }
    }
  }
}
~~~

state enthält die Nachricht, questions unsere Frage route, criteria die zulässigen Antworten. shipping ist unsere Kennung für das Versandteam.

## \3. Das Modell fordert die fehlenden Öffnungszeiten an

Hier ist die vollständige Assistant-Nachricht aus choices[0].message. Der äußere Umschlag mit Verwaltungs-und Abrechnungsdaten ist weggelassen.

Modell → Server · Assistant-Nachricht

~~~text
{
  "role": "assistant",
  "content": null,
  "tool_calls": [{
    "id": "call_hours_1",
    "type": "function",
    "function": {
      "name": "load_knowledge",
      "arguments": "{\"knowledge_id\":\"kb_hours\"}"
    }
  }]
}
~~~

Noch kein Antworttext. Hier fordert das Modell eine Aktion an.

Zuordnung. Diese Kennung wird in der Tool-Rückgabe wiederverwendet.

Auswahl. Genau die zuvor angebotene Wissensbasis wird angefordert.

tool_calls bittet den Server, kb_hours zu laden. call_hours_1 verbindet den Aufruf mit seiner Rückgabe. arguments enthält JSON als Zeichenkette, einen Brief im Brief; deshalb sind dessen Anführungszeichen mit \\" geschrieben.

Im Widget entsteht daraus keine zweite Nachricht. Die Oberfläche könnte zusätzlich eine kurze Aktivität wie „Öffnungszeiten werden geladen“ anzeigen.

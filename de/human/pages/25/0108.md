## Warum Text und strukturierte Daten genügen

In diesem Lauf ist keine Aktion verschwunden. Jede wurde in eine Form übersetzt, die sich über eine Schnittstelle übermitteln lässt:

• Eine Datei finden: Die Suche gibt konkrete Pfade zurück. Der nächste Aufruf übernimmt einen davon.

• Ein Programm prüfen: Das Lesewerkzeug gibt seinen Inhalt zurück. Der Änderungsvorschlag bezieht sich auf genau diesen Text.

• Eine Änderung ausführen: Die Runtime ersetzt einen geprüften Textabschnitt auf dem Datenträger. Das Ergebnis bestätigt den Schreibvorgang.

• Den neuen Zustand testen: Ein Prozess läuft, erzeugt eine Fehlermeldung oder Erfolgsausgabe und endet mit einem Exit-Code. Diese Rückgabe bestimmt den nächsten Schritt.

JSON transportiert dabei eindeutige Felder wie Pfad, Befehl und Rückgabestatus. In diesen Feldern steht wiederum normaler Text: Quellcode, eine Anleitung, eine Fehlermeldung. Die Handlung selbst geschieht in der Runtime.

Die Außenwelt liefert beobachtbare Information. Das Modell fordert einen nächsten Schritt an. Die Runtime führt ihn innerhalb ihrer Grenzen aus und liefert das Ergebnis zurück.

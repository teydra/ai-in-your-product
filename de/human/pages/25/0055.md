~~~text
{
      "role": "user",
      "content": "Mach die Funktion stattdessen in Python."
    }
  ]
}
~~~

Neu. Erst der Verlauf erklärt „die Funktion“.

Damit erhält das Modell den Bezug zu „die Funktion“. Die feste Demo liefert jetzt:

~~~text
def add(a, b):
    return a + b
~~~

Nach dieser Antwort enthält der gespeicherte Verlauf vier Nachrichten: zweimal User, zweimal Assistant. Wer genau hinschaut, merkt: Die erste Frage wurde jetzt zweimal an das Modell geschickt und auch zweimal bezahlt. In einem langen Gespräch zahlst du jede alte Nachricht bei jeder neuen Antwort wieder. Deshalb haben Anbieter Mechanismen eingeführt, um wiederkehrende Anfangsteile günstiger zu verarbeiten, und deshalb entscheiden gute Anwendungen bewusst, was im Verlauf bleibt.

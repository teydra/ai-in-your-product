Wie Agenten Ordnung bekamen

Im November 2024 veröffentlichte Anthropic das Model Context Protocol, kurz MCP: eine offene Beschreibung, wie Anwendungen einem Modell Werkzeuge und Datenquellen anbieten. Statt dass jede Anwendung jeden Dienst einzeln anschließt, beschreibt ein Dienst seine Fähigkeiten einmal, und jede passende Anwendung kann sie nutzen. Innerhalb eines Jahres boten große Anbieter und Tausende von Diensten MCP an.

Im Oktober 2025 folgten Agent Skills: Ordner mit einer SKILL.md, deren Name und Beschreibung im Katalog stehen und deren Inhalt erst bei Bedarf geladen wird. Im Dezember 2025 wurde das Format als offener Standard veröffentlicht. MCP löst das Anschlussproblem; für das Modell bleibt ein MCP-Werkzeug ein Eintrag in seiner Werkzeugliste wie jeder andere. Skills lösen Maras Problem: viel Wissen, ohne alles gleichzeitig lesen zu müssen. 6

## Auch Werkzeuge lassen sich bei Bedarf finden

Bei fünf Werkzeugen kann man alle Definitionen in jeden Request legen. Bei hundert oder tausend wird auch das unpraktisch. Dann kann die Auswahl mehrstufig werden:

Aufgabe → passende Werkzeuge suchen → kurze Trefferliste erhalten → benötigtes Werkzeug laden → Werkzeug verwenden

OpenAI Responses API kann das Feld phase eine Nachricht als commentary oder final_answer kennzeichnen:

~~~text
{
  "type": "message",
  "role": "assistant",
  "phase": "commentary",
  "content": [
    {
      "type": "output_text",
      "text": "Der Test meldet 12.34 statt 12.35. Ich 
korrigiere die Rundungsart und teste erneut."
    }
  ]
}
~~~

phase steht als eigene Angabe neben dem Inhalt; im Text selbst steht kein Kennzeichen. Bei der Abschlussantwort kann an dieser Stelle final_answer stehen. Solche Angaben müssen beim Fortsetzen des Gesprächs erhalten bleiben; sonst kann eine Zwischenmeldung fälschlich als Abschluss behandelt werden. 7

Wie die Nachricht dargestellt wird, entscheidet die Oberfläche. Sie kann Zwischenmeldungen dezent anzeigen, später einklappen oder im Verlauf stehen lassen. Der Codex-App-Server, die Schnittstelle hinter OpenAIs Coding-Agenten Codex, kennt außerdem den Wert partial_answer für bereits ausgegebenen Antworttext, nach dem weitere Ausgabe oder Werkzeugaufrufe folgen können. Andere Systeme verwenden andere Merkmale.

Im Request stehen der Auftrag und die Anweisungen. Der Projektordner und seine Dateien stehen dort nicht. Eine mögliche Antwort ist deshalb:

Im Chat

Assistant

Ohne deine Projektdateien kann ich zunächst nur ein Beispiel zeigen. In Python etwa:

format(preis, '.2f')

Textblock aus der Antwort

~~~text
{
  "type": "output_text",
  "text": "Ohne deine Projektdateien 
kann ich zunächst nur ein Beispiel 
zeigen. In Python etwa:\nformat(preis, 
'.2f')",
  "annotations": []
}
~~~

Rechts steht der Textblock aus der output-Liste der API-Antwort. Die Anwendung nimmt dessen text und zeigt ihn links als Chatblase an.

Der Vorschlag kann als Ausgangspunkt helfen. Aber preis ist ein angenommener Variablenname, und das Modell weiß nicht einmal, ob Maras Projekt Python verwendet. Vor allem: Keine Projektdatei wurde geöffnet, kein Code geändert und kein Test ausgeführt. Alles, was passiert ist, war eine Textantwort. Ein gut eingerichteter Chatbot fragt an dieser Stelle nach den Dateien. Durch eine andere Formulierung bekommt er jedoch keinen Projektzugriff.

Es fehlen zwei Dinge: der tatsächliche Projektinhalt und ein Weg, Arbeit im Projekt ausführen zu lassen.

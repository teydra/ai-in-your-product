tier2.strong bezeichnet eine Modellstufe im gewählten Produktpaket. Die Konfiguration ordnet dieser Stufe ein konkretes Modell zu. Auch hier ist confidence eine Selbsteinschätzung, diesmal darüber, ob der Wechsel hilft.

## Was die Software anschließend macht

Die Software prüft, ob die angeforderte Stufe im laufenden Gespräch angeboten wird und das zugehörige Modell verwendet werden kann.

1 · Erstes Modell

Fordert mit routing_request den Wechsel an.

2 · Teydra-Software

Startet mit dem Modell der Zielstufe einen neuen API-Aufruf.

3 · Neues Modell

Erhält das Gespräch und bereits beschaffte Werkzeugergebnisse. Bearbeitet damit dieselbe Frage weiter.

Das neue Modell kann auf diesen Informationen aufbauen und bei Bedarf weitere Werkzeuge nutzen. Seine fertige Antwort geht zurück in den Chat.

Dieses „Aufleveln“ besteht aus einem weiteren Modellaufruf. Das erste Modell erzeugt die Anforderung; unsere Software führt den Wechsel aus. Der Werkzeugaufruf ist dabei eine interne Ausgabe und erscheint nicht als Nachricht an den Gast.

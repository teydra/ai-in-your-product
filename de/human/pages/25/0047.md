Damit trotzdem ein Gespräch entsteht, macht die Anwendung etwas sehr Einfaches: Sie legt jedem neuen Brief die bisherigen bei. Bei Maras Erklärfeld sieht die zweite Anfrage dann so aus:

Leihregal → Anthropic · zweite Anfrage mit Verlauf

~~~text
{
  "model": "MODELLKENNUNG",
  "max_tokens": 800,
  "system": "Erkläre technische Begriffe auf Deutsch. Setze kein Fachwissen voraus. Erläutere neue Fachwörter sofort und antworte in höchstens vier Sätzen.",
  "messages": [
    {
      "role": "user",
      "content": "Was ist Phantomspeisung?"
    },
    {
      "role": "assistant",
      "content": [{
        "type": "text",
        "text": "Phantomspeisung ist eine Stromversorgung für Mikrofone, die über das normale Mikrofonkabel mitgeliefert wird, meist mit 48 Volt aus dem Mischpult. Kondensatormikrofone, also besonders empfindliche Mikrofone, brauchen diesen Strom zum Arbeiten. Die meisten dynamischen Mikrofone, etwa typische Gesangsmikrofone, kommen ohne aus."
      }]
    },
    {
      "role": "user",
      "content": "Kannst du das noch einfacher sagen?"
    }
  ]
}
~~~

Die erste Frage wird erneut mitgeschickt.

Die eigene Antwort des Modells kommt als Verlauf zurück.

Die frühere Antwort, wörtlich.

Jetzt ergibt „das“ einen Sinn.

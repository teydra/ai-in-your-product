## Wissen bei Bedarf laden

Die Lösung stand schon im Lauf oben. Im ersten Request gab es nur einen kurzen Katalog: den Namen price-changes und einen Satz, wofür diese Anleitung gut ist. Den vollständigen Text hat das Modell erst geladen, als es ihn brauchte. Eine solche Anleitung heißt Skill.

Ein Skill kann beschreiben, wie Code geprüft wird, wie ein Arbeitsablauf beginnt oder wie der Agent mit dem Nutzer umgehen soll. Er kann auf zusätzliche Dateien verweisen, Skripte und Vorlagen bündeln und beschreiben, welche Rückfragen in diesem Kontext hilfreich sind. Ein darin enthaltenes Skript auszuführen benötigt weiterhin ein passendes Werkzeug und die dafür geltenden Rechte.

Wer Rollenspiele kennt, kennt das Prinzip vom Zauberbuch: Niemand trägt alle Zaubersprüche gleichzeitig im Kopf. Man weiß, welche es gibt, und schlägt die richtige Seite auf, wenn man sie braucht.

Mara hatte das gewünschte Ergebnis 12.345 → 12.35 bereits genannt. Dafür musste der Agent nicht noch einmal fragen. Die geladene Anleitung ergänzt die allgemeinere Projektregel und den Testbefehl. Aus Wissen wird Arbeit, wenn der Agent die passenden Werkzeuge anfordert und ihre Ergebnisse auswertet.

Information anfordern → Originaltext erhalten → mit diesem Wissen weiterentscheiden.

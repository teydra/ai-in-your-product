## Welches Modell?

&lt;modellname> wird vor einem echten API-Aufruf durch einen passenden Modellnamen ersetzt.

## Arbeitsregeln

Die Runtime stellt unsere Instruktionen bereit. Hier enthält der Text auch die freigegebenen Projektregeln aus AGENTS.md. Diese Datei wurde von der Anwendung gelesen; ihr Name allein hätte dem Modell nichts mitgeteilt.

## Angebotene Werkzeuge

tools beschreibt die fünf verfügbaren Funktionen. name nennt jeweils das Werkzeug, description seinen Zweck. parameters legt die Form seiner Eingaben fest. Die ausführenden Funktionen liegen in unserer Anwendung.

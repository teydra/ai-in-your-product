Für die sichtbare Seite brauchen wir ein Eingabefeld, einen Senden-Button und Platz für die Antworten. Dieser Teil läuft im Browser und heißt Frontend. Ein zweites Programm nimmt die Nachricht entgegen und ruft das Modell auf: das Backend. Es behält den API-Schlüssel und speichert die Gespräche. Im Beispiel laufen beide Teile auf deinem Rechner.

Der Nutzer sieht zum Beispiel:

System Prompt Du hilfst beim Schreiben kleiner Programme. Antworte auf Deutsch. Gib passenden Code aus und erkläre nur, was zum Verständnis nötig ist. Fehlt eine entscheidende Angabe, frage danach. Du kannst hier keine Dateien öffnen und keinen Code ausführen. Behaupte deshalb nicht, etwas gespeichert oder getestet zu haben.

Chat

User: Addiere zwei Zahlen in JavaScript. Assistant: function add(a, b) { return a + b; }

Der System Prompt ist in dieser Anwendung keine normale Chatnachricht. Eine Anwendung kann ihn in einem eigenen Einstellungsfeld anzeigen und editierbar machen. Unser kleines Beispiel zeigt ihn in der technischen Ansicht; geändert wird er im Backend. Im Gespräch erscheint er nicht als User-oder Assistant-Blase.

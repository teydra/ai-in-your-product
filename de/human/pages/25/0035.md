sechs in einem einzigen Katalogeintrag aus Leihregal, in einem Format, das Mara selbst festgelegt hat:

Ein Katalogeintrag in Leihregals eigenem Format

~~~text
{
  "geraet": {
    "name": "Akku-Lautsprecher L2",
    "akku": true,
    "gewicht_kg": 4.2,
    "zubehoer": ["Netzteil", "Tragegurt"],
    "notiz": null
  }
}
~~~

Objekt: Geschweifte Klammern fassen Felder zusammen.

Text steht in Anführungszeichen.

Wahrheitswert: true oder false.

Zahl: ohne Anführungszeichen, mit Punkt.

Liste in eckigen Klammern.

null: bewusst kein Wert.

Ein Feld verbindet einen Namen mit einem Wert. Feldnamen stehen immer in Anführungszeichen, Textwerte auch, Zahlen und Wahrheitswerte nicht. Kommas trennen Einträge. Ein Wert kann selbst wieder ein Objekt oder eine Liste sein, und genau so entstehen die verschachtelten Strukturen, die auf den ersten Blick einschüchtern.

Um eine Stelle in einer solchen Struktur zu benennen, schreibt man einen Pfad. geraet.name meint das Feld name im Objekt geraet. Listen zählen ab null: geraet.zubehoer[0] ist das Netzteil. Jetzt kannst du auch den Pfad lesen, den Leihregal aus der Antwort von vorhin braucht: content[0].text ist der Text im ersten Inhaltsteil. In diesem einfachen Brief ist das schon der ganze Weg vom Modell zur Antwortblase. Hat eine Antwort mehrere Teile, sucht Leihregal den Teil, dessen type text lautet.

## Von der Antwort zur richtigen Karte

Wie wird aus der Modellausgabe eine Karte, die zum richtigen Gerät gehört? Leihregal geht dafür einen Schritt weiter als das Hotel-Widget: Sein Ausgabevertrag ist ein festes JSON-Schema, wie in Kapitel 2 angekündigt: Die Antwort soll eine Liste von Vorschlägen enthalten, jeder mit einer Gerätereferenz und einer Begründung, dazu eine Liste offener Fragen. Ein dekodierter Modellinhalt sieht dann so aus:

Modell → Leihregal · dekodierter Vorschlag

~~~text
{
  "vorschlaege": [
    {
      "item_ref": "L2",
      "reason": "Im Katalog ist Akkubetrieb angegeben."
    }
  ],
  "offene_fragen": [
    "Findet die Veranstaltung im Trockenen statt?"
  ]
}
~~~

Gerätebezug: Leihregal öffnet damit den echten Katalogeintrag.

Begründung: erscheint als Text auf der Karte.

Offene Frage: erscheint im Kasten „Noch zu klären“.

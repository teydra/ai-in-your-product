Sie beschreibt das gewünschte Ergebnis:

Im Chat

User

Passe die Preisanzeige in meinem Projekt an: immer zwei Nachkommastellen; 12.345 soll 12.35 werden. Teste die Änderung.

Vollständiger Request

~~~text
{
  "model": "<modellname>",
  "instructions": "Du hilfst bei 
Änderungen an Softwareprojekten. 
Arbeite mit den bereitgestellten 
Informationen. Fehlen Dateien, frage 
danach oder kennzeichne Code als 
allgemeines Beispiel. Behaupte 
Änderungen und Tests nur, wenn ihre 
Ausführung belegt ist.",
  "input": [
    {
      "role": "user",
      "content": "Passe die 
Preisanzeige in meinem Projekt an: 
immer zwei Nachkommastellen; 12.345 
soll 12.35 werden. Teste die Änderung."
    }
  ]
}
~~~

Für dieses Kapitel verwenden wir die OpenAI Responses API. 2 Erinnere dich an den Dialekt aus Kapitel 2: Die übergeordneten Anweisungen stehen hier in instructions, die Nachrichten in input. Das Prinzip bleibt gleich. &lt;modellname> ersetzen wir beim Aufruf durch ein verfügbares, geeignetes Modell. Die Modellantworten in diesem Kapitel sind für das Lehrbeispiel vorgegeben. Der Begleitcode führt die gezeigten Dateioperationen und Tests tatsächlich aus, ohne dafür ein KI-Modell aufzurufen.

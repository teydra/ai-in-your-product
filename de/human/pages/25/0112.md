## Skills und Werkzeuge bleiben getrennt

Ein Skill kann sagen: „Für ein Release zuerst Tests ausführen und anschließend den Build prüfen.“ Das Werkzeug run_command ermöglicht die reale Ausführung. Der Skill erteilt aber nicht automatisch die Berechtigung dazu. Daraus ergibt sich eine einfache Aufteilung:

• Skill: Wissen und Vorgehensweise;

• Tool: technische Fähigkeit;

• Runtime: reale Ausführung und Grenzen.

Dadurch kann Wissen geändert werden, ohne neue Rechte zu erzeugen. Und ein Werkzeug kann existieren, ohne dass jeder Skill es benutzen muss. Das ist auch die Rolle eines Skills in der Stani-KI-Methode: Er ist ein KI-lesbares Arbeitsmodul. Er beschreibt Zweck, relevante Quellen, Fähigkeiten, Spielraum und Grenzen so weit, dass das Modell daraus in der konkreten Situation selbst den passenden Weg ableiten kann. Nur wenn eine Reihenfolge wirklich unveränderlich sein muss, wird sie als feste Reihenfolge vorgeschrieben.

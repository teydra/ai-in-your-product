Auch weniger wahrscheinliche Tokens können gewählt werden. Im Beispiel kam nicht die Wiese, sondern die Brücke. Wo verfügbar, verändert der Regler Temperature die Auswahl: Niedrige Werte konzentrieren sie auf wahrscheinliche Fortsetzungen, höhere geben anderen Möglichkeiten mehr Gewicht. Die Banane bleibt in jedem Fall eine Außenseiterin.

## Warum das Modell so überzeugend danebenliegen kann

Jetzt lässt sich erklären, was im Fall Avianca passiert ist.

Die Ausgabe entsteht direkt: Das Modell berechnet ein Token, hängt es an und setzt fort. Ein ganzer Satz muss dafür nicht schon fertig vorliegen. Gelernte sprachliche und logische Zusammenhänge wirken dabei, ohne dass vor jedem Wort eine ausdrückliche Überlegung stehen muss: „Was sage ich jetzt?“

Ein juristischer Schriftsatz hat eine sehr erkennbare Form. Auf eine Behauptung folgt ein Urteil, auf das Urteil ein Gericht, eine Jahreszahl, ein Aktenzeichen. Ein Modell, das Millionen solcher Texte verarbeitet hat, setzt diese Form souverän fort. Ob das Urteil existiert, steht nirgends in der Rechnung. Ein Satz kann so stimmig weiterlaufen, obwohl er auf einer falschen Annahme beruht. Diese Annahme prägt dann den weiteren Kontext.

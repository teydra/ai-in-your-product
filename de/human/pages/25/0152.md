## Das Modell sieht deinen Bildschirm nicht

Jetzt zu Maras zweitem Irrtum. Das eingebaute Modell sieht Leihregal nicht. Es sieht keine Oberfläche, keine Datenbank und keinen Katalog. Es sieht genau einen Brief, Kapitel 2 lässt grüßen: das Vorhaben, die relevanten Bedingungen und den Teil des Katalogs, den Leihregal ihm mitgibt.

Bei einem kleinen Bestand passt die ganze kurze Geräteliste in diesen Kontext. Eine eigene Suche wäre dann zusätzlicher Aufwand ohne Nutzen. So sieht ein kleiner Ausschnitt des fachlichen Inhalts aus, den die Anwendung dem Modell übergibt:

~~~text
{
  "geraete": [
    {
      "referenz": "L1",
      "kategorie": "Lautsprecher",
      "stromversorgung": "Netzstrom"
    },
    {
      "referenz": "L2",
      "kategorie": "Lautsprecher",
      "stromversorgung": "Akku"
    }
  ]
}
~~~

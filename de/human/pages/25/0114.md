Der Agent muss also nicht dauerhaft jede einzelne Schnittstelle vollständig sehen. Dasselbe Prinzip gilt für Skills, Wissenssammlungen, Dokumente, Quellen und andere Ressourcen: Das Modell bekommt zuerst genug Information, um die nächste Auswahl zu treffen.

## Ein Agent kann andere KI-Fähigkeiten anfordern

Ein Werkzeug kann intern selbst wieder ein Modell verwenden:

~~~text
Tool: web_research
→ Runtime startet einen spezialisierten Recherche-Aufruf
→ Recherche-Modell liefert Quellen und Befunde
→ Ergebnis geht als Tool Output an den Hauptagenten 
zurück
~~~

Oder ein Agent erkennt, dass die aktuelle Aufgabe ein anderes Modell oder eine andere Modellstufe braucht. Dann kann die Architektur eine Routing-Anfrage erlauben. Genau formuliert:

Die KI kann den Bedarf für einen anderen Arbeitsschritt oder eine andere Modellstufe erkennen. Die Runtime löst diese Anfrage innerhalb der Modelle, Anbieter und Regeln auf, die das Produkt freigegeben hat.

Damit ist die Auswahl flexibel und trotzdem kontrolliert. Das Modell besitzt keine beliebigen Zugangsdaten zu allen Anbietern. Aber es kann innerhalb des angebotenen Systems mitentscheiden, welche Fähigkeit als Nächstes gebraucht wird.

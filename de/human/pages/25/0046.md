## Ein Stapel Briefe

Erinnere dich an Kapitel 2. Jeder Aufruf ist ein vollständiger Brief, und das Modell liest nur, was darin steht. Nach der Antwort ist für das Modell alles vorbei. Es behält nichts. Die nächste Anfrage trifft ein Modell, das dich nie gesehen hat.

Das Web hatte auch kein Gedächtnis

Das World Wide Web wurde ohne Erinnerung gebaut. Jeder Seitenaufruf über HTTP stand für sich; der Server wusste nicht, ob dieselbe Person eine Sekunde vorher schon einmal da gewesen war. Für Dokumente war das egal. Für einen Warenkorb war es eine Katastrophe.

1994 baute der Netscape-Programmierer Lou Montulli deshalb einen kleinen Trick in den Browser: Der Server durfte ihm einen Zettel mitgeben, den der Browser bei jedem weiteren Aufruf wieder vorzeigte. Der Zettel bekam einen harmlosen Namen, Cookie, und machte das Web zu dem, was es heute ist. 2

Sprachmodelle stehen heute an derselben Stelle. Das Modell bleibt vergesslich. Die Erinnerung baut die Anwendung drumherum.

Bei einem Sprachmodell sieht das so aus. Die Adresse ist eine Internetadresse beim Anbieter, der sogenannte Endpunkt. Auf den Umschlag gehören Angaben, die das Modell selbst nie sieht: ein geheimer Zugangsschlüssel und eine Versionsangabe. Der Inhalt ist ein Text in einem festgelegten Format. Das Modell liest den Inhalt und schreibt eine Antwort, die als neuer Brief zurückkommt. Auch lokale Modelle auf dem eigenen Rechner können so erreichbar sein.

Den Inhalt übertragen wir als JSON, ein Textformat für strukturierte Daten. JSON ist keine Programmiersprache und keine Sprache, die eine KI besonders gut versteht. Es ist eine Konvention, wie man Daten so aufschreibt, dass zwei Programme sich darüber einig sind, was wo steht. JSON beschreibt Daten; unser Programm verarbeitet sie.

Ein Gedanke vorweg, den du später brauchst: Jeder Brief muss alles enthalten, was das Modell für diese eine Antwort braucht. Es gibt keinen Briefwechsel, an den es sich erinnert. Was das bedeutet, merkt Mara am Ende dieses Kapitels.

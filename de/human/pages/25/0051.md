## Vom Eingabefeld zum Modell-Request

Beim Klick auf Senden schickt der Browser zunächst text und chat_id an unser Backend. Das ist Brief 1 aus Kapitel 2, in unserem eigenen Format. text enthält die Nachricht; chat_id bezeichnet das Gespräch in unserer Anwendung. Das Backend sucht dessen gespeicherten Verlauf heraus. Für einen neuen Chat ist er leer.

Die Funktion build_request in chat.py hängt die neue Nachricht an eine Kopie dieses Verlaufs:

~~~text
messages = copy.deepcopy(history) + [
    {"role": "user", "content": text}
]
~~~

Die Kopie lässt den gespeicherten Verlauf unverändert. Mit Modell, System Prompt und Ausgabelimit entsteht daraus Brief 2:

Backend → Anthropic · Brief 2 (1/2)

~~~text
{
  "model": "claude-sonnet-5-5",
  "max_tokens": 800,
  "system": "Du hilfst beim Schreiben kleiner Programme. Antworte auf Deutsch. Gib passenden Code aus und erkläre nur, was zum Verständnis nötig ist. Fehlt eine entscheidende Angabe, frage danach. Du kannst hier keine Dateien öffnen und keinen Code ausführen. Behaupte deshalb nicht, etwas gespeichert oder getestet zu haben.",
  "messages": [
    {
~~~

Modell. Im Live-Modus über --model wählbar.

Obergrenze für neue Tokens, keine Ziellänge.

System Prompt. Arbeitsvertrag, keine Chatblase.

## Die Software bietet ein Werkzeug an

Ein Agent kann zusätzlich zu einem Chatbot Handlungen anfordern und deren reale Ergebnisse weiterverarbeiten. Dafür erweitern wir die Anwendung um Werkzeuge, meist Tools genannt. Ein Tool ist eine Fähigkeit, die unsere Software dem Modell anbietet: eine Datei lesen, einen Befehl ausführen, eine Datenbank abfragen, einen Termin anlegen.

Unser erstes Werkzeug heißt run_command und hat zwei Seiten. In der Anwendung ist es eine Funktion, die einen Befehl im ausgewählten Projekt ausführt und das Ergebnis zurückliefert. Für das Modell ist es eine Beschreibung in der Liste tools des Requests. Neu ist nur dieser Teil:

price-demo → OpenAI · neu im Request

~~~text
{
  "tools": [
    {
      "type": "function",
      "name": "run_command",
      "description": "Führt einen Befehl im ausgewählten Projekt aus und liefert stdout, stderr und exit_code.",
      "parameters": {
        "type": "object",
        "properties": {
          "command": {"type": "string"}
        },
        "required": ["command"],
        "additionalProperties": false
      },
      "strict": true
    }
  ]
}
~~~

Werkzeugname. Frei gewählt; die Runtime ordnet ihn einer Funktion zu.

Beschreibung. Liest das Modell, um zu entscheiden, ob es das Werkzeug braucht.

Schema. Erlaubt genau ein Textfeld command.

Strikt. Aufrufe müssen genau diesem Schema folgen.

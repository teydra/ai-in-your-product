## Welche Skills kennt die KI?

Die Runtime liest name und description aus dem Kopf der bereitgestellten SKILL.md und fügt sie als Katalog in den Modellkontext ein.

name identifiziert die Anleitung. description beschreibt, wann sie passt. Deshalb kann die KI eine Anleitung auswählen, bevor sie deren vollständigen Inhalt kennt.

chat_id fehlt hier; das Feld gehörte zu Brief 1, unserem eigenen Format. AnthropicProvider.__call__ sendet den Anfragekörper mit POST an https://api.anthropic.com/v1/messages. Datenformat, API-Version und Schlüssel stehen in den HTTP-Headern, dem Umschlag. Das Begleitprogramm zeigt Browser-Anfrage und Modell-Request getrennt an, ohne geheime Header offenzulegen: das Kapitel-2-Wissen in echtem Code.

## User und Assistant

Die Antwort kommt nicht als fertige Chatblase zurück. Das Backend liest die Textblöcke aus dem Feld content der Anbieterantwort. Ein Ausschnitt daraus:

~~~text
{
  "role": "assistant",
  "content": [
    {
      "type": "text",
      "text": "function add(a, b) { return a + b; }"
    }
  ],
  "stop_reason": "end_turn"
}
~~~

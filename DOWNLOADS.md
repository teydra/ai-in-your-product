All published book files will be downloadable without an account or paid login. Each release will include a human PDF, every readable human page and its index, the matching AI package and catalogue, and an optional combined offline ZIP. Additional formats such as EPUB may follow.

For now you can download the available repository files with GitHub's **Code > Download ZIP**, or clone the public repository. This archive currently contains the cover, initial resources and publication structure; it does not yet contain the full book.

Actual book releases will be listed in [RELEASES.md](RELEASES.md) and [editions.json](editions.json), with exact file checksums and language/edition identifiers.
